RUDRA EDITS — GitHub Pages Self-Contained Package
=================================================

1. Extract this ZIP.
2. Upload index.html and 404.html to the root of your GitHub repository
   (rudraedits07/rudraedits.github.io) — index.html already includes all
   JavaScript, CSS, and studio images so it works even without folders.
3. In GitHub: Settings -> Pages -> Source: Deploy from a branch -> main / (root).
